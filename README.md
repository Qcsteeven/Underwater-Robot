# 🤖 Underwater Robot Control System Setup

Это руководство содержит пошаговые инструкции для настройки и запуска системы управления подводным роботом, включая клонирование репозитория, создание изолированного виртуального окружения и установку всех необходимых библиотек, перечисленных в **`requirements.txt`**.

## ⚠️ ВАЖНОЕ ПРИМЕЧАНИЕ ОБ ОБОРУДОВАНИИ

Данный проект состоит из двух частей:

1.  **Хост-компьютер** (Windows/Linux/macOS): Для запуска графического интерфейса (GUI) с использованием PyQt5 и обработки ввода с геймпада (pygame).
2.  **Raspberry Pi** (с ОС Linux): Для фактического управления моторами. На нем должен быть установлен и запущен демон **`pigpio`**.

-----

## 💾 1. Клонирование Репозитория

Клонируйте код проекта на ваш хост-компьютер:

1.  Откройте **терминал** или **командную строку**.

2.  Перейдите в каталог, где вы хотите хранить проект.

3.  Выполните команду:

    ```bash
    git clone https://github.com/Qcsteeven/Underwater-Robot.git
    cd Underwater-Robot
    ```

-----

## 🌐 2. Создание и Активация Виртуального Окружения

Создайте виртуальное окружение, чтобы изолировать зависимости проекта.

### 2.1. Создание Окружения

В корневой папке проекта (`Underwater-Robot`) выполните:

```bash
python3 -m venv venv
```

### 2.2. Активация Окружения

Активируйте окружение. Перед командной строкой должен появиться префикс `(venv)`.

| Операционная система | Команда активации |
| :--- | :--- |
| **Linux/macOS** | `source venv/bin/activate` |
| **Windows (Command Prompt)** | `venv\Scripts\activate.bat` |
| **Windows (PowerShell)** | `venv\Scripts\Activate.ps1` |

-----

## 📦 3. Установка Библиотек

Установка всех необходимых зависимостей происходит из файла **`requirements.txt`**.

1.  Убедитесь, что виртуальное окружение **активно**.

2.  Выполните команду:

    ```bash
    pip install -r requirements.txt
    ```

> **Ожидаемые библиотеки:** В `requirements.txt` должны быть перечислены **`PyQt5`**, **`pygame`**, **`pigpio`**, **`opencv-python`**, и **`numpy`**. `pip` автоматически установит все, что требуется для работы GUI, геймпада, видео и удаленного управления моторами.

-----

## ⚙️ 4. Настройка Конфигурации

Отредактируйте файл **`config.py`**, чтобы указать адреса вашего оборудования.

Откройте `config.py` и измените следующие параметры:

| Переменная | Описание | Пример значения | Цель |
| :--- | :--- | :--- | :--- |
| `PI_HOST` | **IP-адрес Raspberry Pi** с запущенным демоном `pigpio`. | `'192.168.1.100'` | Управление моторами по сети. |
| `RTSP_URL` | **RTSP-поток** с вашей подводной камеры. | `"rtsp://admin:admin@192.168.1.88:554/11"` | Получение видеопотока для отображения и записи. |

-----

## ▶️ 5. Запуск Системы

1.  **На Raspberry Pi:** Убедитесь, что демон `pigpio` запущен:

    ```bash
    sudo pigpiod
    ```

2.  **На Хост-компьютере:** Убедитесь, что виртуальное окружение **активно** и **геймпад подключен**.

3.  Запустите основной GUI-скрипт:

    ```bash
    python main_gui.py
    ```

Приложение запустит графический интерфейс, установит соединение с Raspberry Pi для управления моторами и попытается подключиться к RTSP-камере для отображения видео.

### Возможные проблемы при запуске:

  * **Ошибка `ConnectionError`:** Если приложение не может подключиться к `PI_HOST`, оно не запустится, так как моторы не будут управляемы. Проверьте IP-адрес и убедитесь, что `pigpiod` запущен на Pi.
  * **Камера:** Если камера не подключена, GUI запустится, но отобразит ошибку подключения к камере.****
